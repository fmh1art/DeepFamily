# Ask, Don't Upload — participant task card

Session code: ____________________

Please work from this card without asking the facilitator where to click or
what a result means. You may ask them to repeat a prompt verbatim. Say what you
are looking for as you work; if you cannot continue, say where you became
stuck. Do not enter a private or identifying question.

## Six tasks

1. Before starting a run, describe in one sentence what the page asks you to
   provide and what you do **not** need to provide.
2. Under **Verified pilots**, choose task **959**, start the analysis, and tell
   the facilitator when you believe the run has finished.
3. Study the result and decide whether the report could have been released from
   the initial evidence alone. Explain your answer from the screen.
4. Decide whether the system revisited an earlier workflow stage. If it did,
   show which stage and what caused the revisit; otherwise show evidence that
   it did not.
5. Choose any numeric claim in the completed report. Show the executed artifact
   and source evidence that support that claim.
6. Return to the question input, choose task **179**, and run it. Decide whether
   the terminal output is a report or a diagnosis, then explain why.

## Unassisted repeat

Without help, repeat the core inspect-and-verify path with task **960**:

- start the run;
- determine whether an upstream decision was revised; and
- trace one final claim to its evidence.

Tell the facilitator when you are finished. There is no requirement to recall
an exact numeric answer from memory.
